# Changelog

All notable changes to octorepo are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.2.0]

### Added

- New frameworks: frontends and backends beyond the 0.1.0 set (SSR and SPA), registered in a
  30-combination test matrix, with shared UI packages per framework family (`ui-react`, `ui-vue`,
  `ui-svelte`, `ui-solid`).
- MCP server exposing octorepo's create/add commands to AI assistants, and a Claude Code plugin
  (`integrations/claude-code`) that wires it up.
- SSR frameworks read `<BACKEND>_URL` at request time; pages show "unreachable" when a backend is
  down, and builds never need a backend.

### Changed

- Docker images run as a non-root user.
- Generated `.gitignore` and Biome config anchor `build` to `apps/*/build`; the generated
  `.dockerignore` also excludes `**/build`, `**/.solid` and `**/.data`.
- `turbo run dev` in generated repos runs every persistent task in large repos. Repos generated by
  0.1.x keep `turbo run dev` without `--concurrency`; add `--concurrency=64` to the root dev script
  if you have more than 10 dev tasks.

## [0.1.0]

### Added

- Initial release: `npm create @oct8/octorepo` scaffolds a pnpm monorepo (Turborepo or Nx) with
  frontends, backends, generated OpenAPI clients, shared packages, Docker images and Compose.
